# MiniMax Token Plan Dashboard

Web Dashboard for monitoring MiniMax Token Plan usage. 5 hour and weekly limits are displayed and can be easily compared with the usage.

## Screenshot

![Preview](screenshot.jpg)

## Installation

```bash
# Clone or download the project
cd minimax-token-plan-dashboard

# Install dependencies
npm install

# Start the dashboard
npm start
```

Open **http://localhost:7777** in your browser.
